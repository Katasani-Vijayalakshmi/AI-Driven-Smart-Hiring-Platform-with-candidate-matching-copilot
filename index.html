Powered by AI Technology
Everything you need for a modern, intelligent hiring pipeline
📄
Resume Parsing
PDF & DOCX parsing using PyMuPDF and python-docx. Extracts education, skills, experience, and projects automatically.
🧠
NLP Extraction
spaCy and HuggingFace Transformers for intelligent entity recognition. Named Entity Recognition (NER) for structured candidate profiling.
🎯
AI Matching Score
Cosine similarity and TF-IDF matching engine calculates a hiring score for each candidate-job pair in real time.
📊
Analytics Dashboard
Skill distribution pie charts, top 20 skills bar chart, score distributions, and pipeline status analytics for recruiters.
🔐
Secure Authentication
JWT-based auth with bcrypt password hashing. Role-based access control separates candidate and recruiter portals completely.
🗄️
MySQL Persistence
All data stored in MySQL via SQLAlchemy ORM. Structured tables for users, jobs, and applications with full relational integrity.
Tech Stack
Built with industry-standard tools and frameworks
